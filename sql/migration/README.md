-- =====================================================================
-- 迁移脚本规范
-- =====================================================================
--
-- 这个目录存放「增量变更」脚本，用于组员之间同步表结构。
--
-- 【为什么需要它】
--   sql/init.sql 里全是 CREATE TABLE IF NOT EXISTS，
--   对已存在的表加字段、加索引是完全不生效的。
--   所以任何「表结构变更」都必须写成这里的迁移脚本。
--
-- 【文件命名】
--   三位数字开头，按执行顺序递增：
--       001_add_goods_category_id.sql
--       002_add_order_remark.sql
--       003_xxx.sql
--   数字必须连续递增，不能重号（否则执行顺序不确定）。
--
-- 【写法要求：必须幂等】
--   脚本要能被重复执行而不报错，因为组员可能不小心执行多次。
--   加字段请用 information_schema 先判断是否存在，参考 001 的写法。
--
-- 【执行方式】
--   双击项目根目录下的  sync.bat  即可自动按序执行本目录所有脚本。
--
-- 【工作流】
--   1. 你修改了表结构（加字段、改类型、加索引...）
--   2. 在这里新建下一个编号的 .sql，写幂等脚本
--   3. git add / commit / push
--   4. 通知组员 git pull
--   5. 组员双击 sync.bat，结构就和你一致了
--
-- 【注意】
--   - 不要在本目录放初始化数据（初始化数据应写进 init.sql 或单独的测试数据脚本）
--   - 不要删除或修改已提交的脚本，只能新增（别人的环境可能已经执行过）
-- =====================================================================
